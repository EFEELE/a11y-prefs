# a11y-prefs

An accessibility preferences panel, shipped as a web component. No dependencies,
works anywhere a browser does: plain HTML, Vite, React, Astro, PHP, WordPress.

This is a **preferences panel for visitors** — they choose larger text, more
contrast, no animations, and the choice sticks in their browser. It is not a
tool that claims to make a site accessible on its own. That part still happens
in your HTML.

MIT licensed. Use it, fork it, ship it to clients, no strings.

Work in progress.
